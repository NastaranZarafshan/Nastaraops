What is actually measured

Evidence support ≠ source trust ≠ answer release

METHOD

Evidence verdictSupported, unsupported, contradicted, abstention; compared with reference labels.

Source trust policyDemo or untrusted evidence is never approved for external communication, even if it textually supports an answer.

Confusion matrix / per-class P·R·F1Only successfully judged cases count. A failed model call lowers coverage; it does not become an invented prediction.

Retrieval metricsCalculated from fixture source IDs only. They do not benchmark the live Qdrant retriever.

METHOD

Frozen judge, separate test setThe evidence policy is unchanged. New authored sources and labels were not used for prompt tuning; annotations are not independently human-adjudicated.

Confidence intervalsSource-entity cluster bootstrap: resample 25 documents and reuse the same sampled entities across repeats. Descriptive intervals; not general-population certainty.

Integrity & exportsDataset and judge SHA256 plus downloadable Markdown and CSV reports. Model weight digest must be recorded separately.
